# End-to-End Sales Data Management & Analytics System

## Project Overview

This project aims to build an end-to-end sales data management and analytics system using free and accessible tools.

The system will support structured transaction data storage, data validation, ETL processes, SQL-based analytics, and interactive dashboards.

## Dataset

- **File:** Sales_dataset.csv
- **Format:** CSV (semicolon delimiter)
- **Records:** 2,826 reported rows
- **Columns:** 18
- **Period:** 2023–2025
- **Product Categories:** 7
- **Countries:** 19

## Technology Stack

- Python
- Pandas
- PostgreSQL
- Supabase
- SQL
- Streamlit
- Google Data Studio
- GitHub

## Project Objectives

1. Perform data profiling and quality assessment.
2. Design a normalized relational database.
3. Build an ETL pipeline.
4. Implement database constraints and validation.
5. Develop SQL analytics views.
6. Build an interactive transaction input application.
7. Create an interactive sales dashboard.
8. Test the complete data pipeline.

## Important Data Notes

- Estimated Cost Price is assumed to be 50% of MSRP, not actual company cost data.
- Three records require further investigation because reported category distributions total 2,823 rather than 2,826.
- CUSTOMER_CODE requires verification before being used as a customer identifier.
